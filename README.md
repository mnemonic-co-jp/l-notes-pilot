# 俺のライナーノーツ

既存のアナログレコードと CD に、自分のライナーノーツを署名して残すための棚です。星は置きません。いいねは数えます。帯は、編集部だけが付けます。

最初の棚は、品番を手で確かめた十五枚です。ジャケットは原盤の絵柄ではなく、書誌のための組版です。Amazon へのリンクは検索結果で、Discogs は書誌の照合先です。

原稿、筆名、いいねはサーバへ送られません。開いているブラウザの中だけに残ります。

## 起動

```bash
npm install
npm run dev
```

[http://127.0.0.1:4317](http://127.0.0.1:4317) を開きます。

## この棚でできること

- 音盤の書誌を見て、稿を読む
- 筆名を定めて、400字以上のライナーを綴じる
- 稿を推す。推した数は、書き手の称号を動かす
- 帯の付いた稿だけを、選集として読む
- 自分の原稿をテキストで書き出す

称号は、見習い筆者、通、訳知り、音楽評論家、選者です。音楽評論家に届くと、肩書きを自分で名乗れます。デモでは「試験読者」を足して、称号の動きだけを確認できます。試験読者は実在せず、帯は付きません。

編集方針は、サイト内の編集後記に書いてあります。
